BotMode Lab Analytics (private channel-management tool)

"BotMode Lab Analytics" is a private Google OAuth integration (Google Cloud project "BotMode Lab Publisher"). It is used only by the BotMode Lab operator, for the BotMode Lab YouTube channel. It is not offered to the public, and there is no sign-up.

With the operator's authorization, it: - reads channel and video statistics and YouTube Analytics reports (for example views, watch time, average view duration and percentage, likes, shares and subscribers gained) to improve the tutorials; - can upload videos to the BotMode Lab channel, but only after the operator explicitly approves each upload. Videos are currently published manually.

It uses YouTube API Services. See the YouTube Terms of Service.
