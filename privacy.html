BotMode Lab Privacy Policy

Effective date: November 7, 2026 Operator: Daniel Lopez Loaiza, operating as BotMode Lab Contact: botmodelab@gmail.com

1. Scope

This policy covers this website and "BotMode Lab Analytics", a private Google OAuth desktop integration in the Google Cloud project "BotMode Lab Publisher". The operator uses it only for the BotMode Lab YouTube channel. It is not a public app, and we do not accept other people's Google accounts.

2. This website

This site is a static website hosted on GitHub Pages. It has no analytics, cookies set by us, or third-party scripts. GitHub states that when a GitHub Pages site is visited, the visitor's IP address is logged and stored for security purposes (GitHub Pages docs; see the GitHub Privacy Statement). We do not receive or control those logs.

3. Google and YouTube data the tool accesses

When the operator signs in with Google and grants permission, the tool requests these scopes:

Scope Purpose
youtube.readonly Read the BotMode Lab channel's details and its videos' statistics (for example views, likes and comments).
yt-analytics.readonly Read aggregated YouTube Analytics reports for the channel (for example views, watch time, average view duration and percentage, likes, shares and subscribers gained).
youtube.upload Upload a video to the BotMode Lab channel, only after the operator explicitly approves that upload. Publishing is currently done manually.

The tool does not request Gmail, Drive, contacts or other Google data. It works with channel-level and video-level statistics, not information about individual viewers.

4. How the data is used

The data is used only to manage and improve the BotMode Lab channel: checking performance, planning tutorials and, when approved, uploading videos. It is not sold, not used for advertising, and not used to profile individuals.

5. Storage and security

  • The tool runs on a cloud-hosted computer used by the operator and the operator's AI assistant.
  • OAuth tokens are stored in a folder restricted to the owner account, and the client secret is not written to disk. Our tools are designed to avoid showing tokens in logs or chat. No method is perfectly secure.
  • Retrieved statistics and upload records (for example video ID, privacy status, URL and counts) are stored in local project files, such as a metrics snapshot file and per-video upload records.

6. AI processing and other parties

The operator uses Grok Bot, an AI assistant provided by SpaceX Super Intelligence LLC (formerly xAI), to run the tool and analyze results. The retrieved channel statistics are therefore processed by that service under the SpaceXSI/xAI Privacy Policy. Google/YouTube and GitHub (for website hosting) process data under their own policies. Otherwise we do not transfer this data to other parties, except where required by law.

7. Google API Services User Data Policy (commitment)

BotMode Lab Analytics' use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements. BotMode Lab Analytics has not been reviewed or verified by Google.

8. YouTube API Services

This tool uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy.

9. Retention, revocation and deletion

  • Retention: we commit to refreshing or deleting stored YouTube statistics within 30 days of retrieval. This is done by the operator through a periodic manual review supported by a local audit tool. It is not deleted automatically.
  • Revoking access: you can revoke the tool's access at any time at Google Account permissions. Revoking stops new access. It does not automatically delete data already stored locally.
  • After revocation: when the operator revokes access or learns of a revocation, the operator commits to deleting the stored OAuth tokens and stored YouTube statistics within 7 days.
  • Deletion requests: email botmodelab@gmail.com. We commit to handling requests within 7 days and to telling you what was deleted. Copies already processed by the AI assistant provider (section 6) are governed by that provider's retention and deletion practices, and we cannot guarantee their deletion.

10. Children

This site and tool are not directed at children.

11. Changes

Changes to this policy will be posted on this page with a new effective date.
